# Manuscript

LaTeX source of the paper based on `beltloop`. Elsevier `elsarticle` class, set up
for Applied Mathematical Modelling: preprint layout, 12 pt, single column, line numbers,
numbered references with full author lists (`elsarticle-num-names`). Needs the TeX Live
packages `elsarticle` (texlive-publishers), `lmodern` and `rotating`.

Build from this folder:

```
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

- `main.tex`: preamble, front matter (title, author, abstract, keywords) and the order of the
  sections and appendices (A variational form, transfer matrices and orthogonality, B numerical
  methods, C consistency checks and cross-comparisons, D drive without speed control and validity
  conditions, E reduced table of cases).
- `supplementary.tex`: supplementary material (S1 full table of cases, S2 application to three
  field conveyors, S3 drive on the return strand and initial crawl, S4 parameters of the
  verification conveyors, S5 further details moved from the article: step onset of the
  resistances, threshold of the mode A1, short conveyors, the drive and the stored belt of
  Harrison's conveyor, inconsistencies in the example of Song et al.), compiled to PDF after the
  article, whose labels it reads through `xr` (prefix `A-`):

  ```
  pdflatex supplementary && bibtex supplementary && pdflatex supplementary && pdflatex supplementary
  ```

  The wide generated tables (full table of cases, applications) open a `widetable` float: a
  landscape page in the supplementary material.

Length in the journal layouts (estimate; the same sources, Times font):

```
cp main.bbl main_3p.bbl
pdflatex -jobname=main_3p "\def\paperlayout{3p,times}\input{main}"   # run twice
```

(`1p` and `5p` likewise; in `5p`, two columns, figures span the page and long equations may
overflow, so the count is approximate.)
- `sections/`: one file per section and appendix (`supp_*` for the supplementary material);
  `notation.tex` is the table of notation (Section 2).
- `macros.tex`: notation and editing macros (`\TODO`, `\NOTE`).
- `cover_letter.tex`: cover letter for the submission (`pdflatex cover_letter`).
- `make_submission.sh`: after a full build of the article and the supplementary material,
  writes `submission/` (git-ignored) with one flat `manuscript.tex` (inputs, numbers and
  bibliography expanded), the figure files and `supplementary_material.pdf`, for the journal's
  online system; it compiles the copy and checks that its text matches `main.pdf` (needs
  `latexpand`, TeX Live `texlive-extra-utils`).
- `paper_numbers.tex`: generated by `maps/paper_numbers.py`; every number quoted in the
  text is a macro defined there. Do not type computed numbers in the text.
- `figures/`: figures drawn for the paper only (`fig_loop.pdf`, by `maps/fig_loop.py`).
- `references.bib`: the bibliography of the paper.
- `highlights.tex`: the highlights for the submission, with the same number macros;
  build with `pdflatex highlights`.

Figures and tables are read directly from the code outputs
(`../maps/figures/paper/`, `../validation/figures/`, `figures/`), so regenerating them with
`maps/paper_figures.py`, `maps/paper_tables.py`, `validation/fig_lumped_validation.py` and
`maps/fig_loop.py` updates the manuscript.

Numbers: `python maps/paper_numbers.py` (from the repository root) rewrites
`paper_numbers.tex` from the cached data in a few seconds; `--check` reports whether the file is
up to date and `--recompute` refreshes the slow inputs first (Lodewijks' starts and the
lumped-mass validation, about 1 min). `tests/test_paper_numbers.py` fails if the file differs
from the generator, if the text uses an undefined `\Num` macro, or if a key number moves.
Example: `the measured slow period, \qty{\NumHarrisonSlowMeas}{\second}, is approached
(\qty{\NumHarrisonSlowModel}{\second}, $+\qty{\NumHarrisonSlowExcess}{\percent}$) ...`.
The comment after each macro says what it is.
